# מחיר·עגלה — השוואת מחירי סופרמרקטים בישראל

אתר מקומי (רץ אצלכם על המחשב) שמוריד את קובצי המחירים הרשמיים
שכל רשתות השיווק בישראל מחויבות לפרסם לפי
[חוק קידום התחרות בענף המזון ("חוק שקיפות מחירים")](https://www.gov.il/he/pages/cpfta_prices_regulations),
מאחד אותם למסד נתונים אחד, ומאפשר:

- **לחפש מוצר** לפי שם, יצרן או ברקוד
- **להשוות את המחיר בין הרשתות** — הכי זול / חציון / הכי יקר בכל רשת, וכל הסניפים ממוינים לפי מחיר
- **לסנן לפי עיר**
- **להשוות סל קניות שלם** — לכל רשת, הסניף הזול ביותר לסל, כולל פירוט ומוצרים חסרים

**מחירים רגילים בלבד.** האתר מציג את המחיר הרגיל על המדף (`ItemPrice` מקובצי
`PriceFull`). קובצי המבצעים (`Promo` / `PromoFull`) לא מורדים ולא נטענים בכלל,
כך שמבצעים, הנחות כמות והנחות מועדון לא משפיעים על שום מחיר באתר.

כל הכלים חינמיים וקוד-פתוח: Python, PostgreSQL, Flask, וחבילת
[`il-supermarket-scraper`](https://github.com/OpenIsraeliSupermarkets/israeli-supermarket-scarpers)
להורדת הקבצים מאתרי הרשתות.

## איך זה בנוי

```
gov.il → אתרי הרשתות
        │
        ▼
etl/download.py   מוריד רק קובצי Stores + PriceFull   →  dumps/<רשת>/*.xml
        │
        ▼
etl/load.py       קורא את ה-XML וטוען ל-PostgreSQL     →  stores, prices, products
        │
        ▼
backend/app.py    Flask API + אתר החיפוש וההשוואה      →  http://localhost:5000
```

| טבלה | תוכן |
|---|---|
| `stores` | כל הסניפים של כל הרשתות (שם, כתובת, עיר) |
| `prices` | מחיר רגיל לכל מוצר בכל סניף — שורה אחת לכל (רשת, סניף, ברקוד) |
| `products` | קטלוג מוצרים לחיפוש מהיר (נבנה מחדש בסוף כל טעינה) |
| `store_snapshots` | איזה קובץ נטען אחרון לכל סניף ומתי |

כמה פרטים שכדאי להכיר:

- **כל קובץ PriceFull הוא תמונת מצב מלאה של סניף**, ולכן טעינה שלו מחליפה את
  כל המחירים של אותו סניף. אפשר להריץ את הטעינה שוב ושוב בלי כפילויות, וקובץ
  ישן לא דורס קובץ חדש.
- **ההשוואה בין רשתות היא לפי ברקוד.** קודים פנימיים של רשת (`ItemType=0`,
  בעיקר ירקות ופירות במשקל) לא נכללים, כי הם שונים בכל רשת ואי אפשר להשוות אותם.
- **מוצר שקיל** (`bIsWeighted=1`) — המחיר הוא לק"ג, ובסל הכמות היא בק"ג.
- כל רשת מפרסמת מבנה XML מעט שונה (אותיות גדולות/קטנות, `Items/Item` מול
  `Products/Product`, קידוד UTF-16 וכו'). `etl/xml_reader.py` מזהה שורות לפי
  השדות שלהן ולא לפי שמות העטיפה, כך שמבנה אחד קורא את כל הרשתות.

## התקנה (פעם אחת)

### 1. דרישות מוקדמות
- Python 3.10 ומעלה
- PostgreSQL (חינמי): [הורדה מ-postgresql.org](https://www.postgresql.org/download/)
  או ב-macOS: `brew install postgresql`, ב-Ubuntu: `sudo apt install postgresql`

### 2. יצירת מסד הנתונים
```bash
createdb supermarket_prices
```

### 3. הגדרת הפרויקט
```bash
cd israeli-supermarket-prices
python -m venv venv
source venv/bin/activate        # ב-Windows: venv\Scripts\activate
pip install -r requirements.txt

cp .env.example .env
# ערכו את .env עם פרטי ה-Postgres שלכם
```

## הרצה

### שלב 1: הבאת הנתונים
```bash
./run_etl.sh
```
מריץ ברצף הורדה (`etl/download.py`) ואז טעינה (`etl/load.py`).
הטבלאות נוצרות אוטומטית בהרצה הראשונה.

הורדה מלאה של כל הרשתות לוקחת זמן (מאות סניפים, קובץ לכל סניף). לבדיקה
מהירה בהתחלה, בטלו את ההערה ב-`.env`:
```
ENABLED_SCRAPERS=SHUFERSAL,RAMI_LEVY
LIMIT=5
```
(`LIMIT` הוא מספר הקבצים לכל רשת, כך שבבדיקה כזו ייתכן שקובץ הסניפים לא
יורד ולא יופיעו ערים — זה תקין.) כשהכול עובד, הסירו את ההגבלות והריצו שוב.

### שלב 2: הרצת האתר
```bash
./run_server.sh
```
ופתחו בדפדפן: **http://localhost:5000**

### רענון מחירים
הרשתות מעדכנות את הקבצים כל יום. כדי לרענן, פשוט הריצו שוב `./run_etl.sh`
(אפשר לתזמן עם cron / Task Scheduler). ההורדה מתחילה מתיקייה נקייה, והטעינה
מחליפה את המחירים של כל סניף בתמונת המצב החדשה.

### בדיקות
```bash
pip install pytest
python -m pytest tests
```

## מבנה הפרויקט

```
db/schema.sql                 סכמת ה-SQL
etl/download.py               שלב 1: הורדת קובצי Stores + PriceFull
etl/xml_reader.py             קריאת ה-XML של כל הרשתות
etl/load.py                   שלב 2: טעינה ל-PostgreSQL ובניית קטלוג המוצרים
etl/chains.py                 שמות הרשתות בעברית
backend/app.py                שרת Flask + API
backend/queries.py            שאילתות SQL
frontend/                     דף האתר (HTML / CSS / JS)
tests/                        בדיקות + קובצי XML לדוגמה בשלושה מבנים
```

### API
| כתובת | תיאור |
|---|---|
| `GET /api/search?q=חלב תנובה` | חיפוש לפי מילים או ברקוד |
| `GET /api/products/<ברקוד>?city=חיפה` | השוואה לפי רשת + כל הסניפים |
| `POST /api/basket` `{"items":[{"item_code":"...","qty":2}],"city":"..."}` | השוואת סל |
| `GET /api/cities` · `/api/supermarkets` · `/api/stats` | נתוני עזר |

## הערות חשובות

- **גישה מחוץ לישראל**: חלק מאתרי הרשתות חסומים לכתובות IP מחוץ לישראל.
  אם מריצים מחו"ל, חלק מהרשתות ייכשלו בהורדה — זה לא באג בקוד.
- **תלות בחבילה קהילתית**: `il-supermarket-scraper` מתוחזקת בקהילה. לפעמים רשת
  משנה את האתר שלה ושוברת את ההורדה שלה לזמן מה; עדכון החבילה
  (`pip install -U il-supermarket-scraper`) בדרך כלל פותר.
- **ערים**: השמות מגיעים כמו שהרשת כתבה אותם (למשל "תל אביב" מול "תל אביב יפו"),
  וחלק מהרשתות מפרסמות קוד עיר מספרי במקום שם — סניפים כאלה לא יופיעו בסינון לפי עיר.
- **שדרוג מגרסה קודמת**: אם הרצתם בעבר גרסה שטענה גם מבצעים, צרו את מסד
  הנתונים מחדש (`dropdb supermarket_prices && createdb supermarket_prices`).
- **שימוש אישי**: המחירים מתפרסמים לפי חובה חוקית לשקיפות צרכנית. הפרויקט
  הוא כלי אישי להצגה והשוואה שלהם, ולא שירות מסחרי.
